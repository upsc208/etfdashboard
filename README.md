# KRX ETF Intelligence Hub (한국 ETF 종합 EDA 대시보드)

네이버 증권 실시간 ETF API를 통해 한국 시장에 상장된 전체 ETF(1,070+개) 데이터를 수집하고, 다차원 탐색적 데이터 분석(EDA)과 시각화를 제공하는 정적 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 실시간 데이터 수집 & 정적 배포 최적화
- **실시간 API 자동 페이지네이션**: `listingType=aumDesc&size=100&index=...` 전체 페이지 실시간 연동
- **CORS 프록시 & 로컬 스냅샷 페일오버**: 브라우저 직접 호출, CORS 프록시, 로컬 `data.json` 백업 3단계 안전 로드
- **자동 갱신 & 수동 새로고침**: 30초 / 1분 / 5분 실시간 주기 갱신 및 원클릭 즉각 갱신
- **정적 호스팅 100% 호환**: GitHub Pages, Vercel, Netlify, Cloudflare Pages, AWS S3 등에 빌드 과정 없이 바로 배포 가능

### 2. 종합 EDA & 인터랙티브 시각화 (Apache ECharts)
- **📊 핵심 KPI 카드**: 전체 상장수, 시장 총 순자산(AUM), 당일 총 거래대금, 시장 등락폭(Market Breadth), 평균 iNAV 괴리율, 당일 최고 상승/거래 종목
- **🗺️ 마켓 트리맵 & 히트맵**: AUM 규모별 타일 크기 + 당일/1M/3M/6M 수익률 및 괴리율 색상 매핑
- **🏢 운용사/브랜드 점유율 분석**: 삼성 KODEX, 미래에셋 TIGER, 한국투자 ACE, KB RISE, 한화 PLUS, 신한 SOL 등 AUM 점유율 및 성과 비교
- **📂 자산군 & 테마 분석**: 국내주식, 해외주식, 국내외 채권, 원자재, 환율, 특수 테마(배당/커버드콜, 액티브, 레버리지/인버스) 분류
- **📈 수익률 & 분포 분석**: 기간별 Top 10 / Bottom 10 랭킹, 수익률 구간 히스토그램, 1M vs 3M 다차원 산점도
- **💧 유동성 & 회전율 분석**: AUM vs 당일 거래대금 산점도(Log Scale), 자산 회전율 상위 종목 발굴
- **⚠️ 괴리율 리스크 모니터링**: 시장가와 순자산가치(iNAV) 간 괴리율 극단값(고평가 vs 저평가) 및 경보 필터

### 3. 고성능 데이터 탐색기 & 내보내기
- **실시간 다중 필터 & 검색**: 종목명, 코드, 운용사, 자산군, 특성 태그 필터링
- **다이나믹 컬럼 정렬 & 페이지네이션**: 25 / 50 / 100개씩 보기
- **종목 상세 모달**: 클릭 시 가격 정보, 괴리율, 기간별 수익률, 네이버 증권 링크 확인
- **CSV 데이터 내보내기**: 필터링된 데이터를 엑셀/CSV 파일로 원클릭 다운로드
- **다크 / 라이트 모드 지원**: 사용자 선호 테마 지원

## 🚀 로컬 실행 방법

### Python uv를 통한 로컬 서버 실행:
```bash
# 로컬 웹 서버 실행
uv run python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속

### 최신 데이터 스냅샷 업데이트:
```bash
uv run update_data.py
```

## 🌐 정적 웹사이트 배포 가이드

### GitHub Pages 배포
1. 저장소의 `main` 브랜치에 코드를 푸시합니다.
2. GitHub 저장소의 **Settings** > **Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 설정하고 `/ (root)`를 선택 후 저장합니다.
